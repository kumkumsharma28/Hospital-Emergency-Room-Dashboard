# 🏥 Hospital Emergency Room Dashboard

## 📊 Project Overview

An interactive Hospital Emergency Room Dashboard developed using
Microsoft Excel to analyze patient visits, waiting times, satisfaction
scores, admission status, demographics, and department referrals.

## 🎯 Project Objectives

- Analyze emergency room patient visits.
- Monitor average patient waiting time.
- Evaluate patient satisfaction scores.
- Compare admitted and non-admitted patients.
- Analyze patient distribution by age and gender.
- Identify department referral patterns.

## 📈 Dashboard Features

- Interactive monthly filters
- Year selection for 2023 and 2024
- Patient count and average wait time KPIs
- Patient satisfaction score
- Admission status analysis
- Gender-wise analysis
- Age group analysis
- Department referral analysis

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- Charts and Data Visualization
- Interactive Slicers

## 💡 Key Learnings

This project helped me improve my skills in data analysis,
dashboard design, and data visualization using Excel.
